# BauRechner

Flutter MVP: room dimensions, wall area minus windows/doors, optional ceiling, paint layers, coverage, waste percentage, price estimate, saved projects.

## Run
1. Install Flutter SDK and Android Studio with Android SDK.
2. Open a terminal in this project folder.
3. Run `flutter pub get`
4. Run `flutter run`

Build an Android APK with `flutter build apk --release`. The file is normally at `build/app/outputs/flutter-apk/app-release.apk`.

Note: this is the full MVP source project, but it has not been compiled/tested in this environment. Actual APK creation requires a working local Flutter/Android SDK setup.
